# Types of Mart Tables

There are two types of big category tables in the mart layer

## Fact Tables

- Transaction
- Periodic Snapshot
- Accumulating Snapshot
- Factless

## Dimension Tables

- Standard
- Degenerate
- Conformed
- Junk
- Role-Playing
- Outrigger
- Shrunken
- Swappable
- Step
- Slowly Changing Dimension (SCD): Type 1~3
