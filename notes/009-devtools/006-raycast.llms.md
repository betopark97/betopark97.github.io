# Raycast

Raycast is a fast, highly customizable productivity launcher for macOS, first, designed to replace Apple’s native Spotlight. It lets you search files, launch apps, manage clipboard history, run custom scripts, and execute AI tasks using quick keyboard shortcuts.

The main advantage of using Raycast for me, is that there is a \[Store (Raycast)\] where you can download extensions that the community has made.

Now one caveat would be that installing an extension brings a lot of clutter to Raycast when you press `command + space`, that’s why you have to go to \[Extensions (Raycast Settings)\] and de-select what seems best for you.

The ones that I use and recommend are:

- Brew
  - Clean up
  - Manage Services
  - Services Menu Bar
  - Upgrade
- Coffee
  - Caffeinate Status Menu Bar
  - Toggle Caffeinate
