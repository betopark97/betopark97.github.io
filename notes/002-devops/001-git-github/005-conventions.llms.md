# Conventions

These are some of the conventions I follow and would recommend. This is not an official way to work with git or github, but just a curated guideline that I follow when I work.

## Git Branches

1.  Lowercase and hyphen-separated. (e.g., `feature/new-login`, `bugfix/header-styling`)
2.  Alphanumeric characters and hyphen. (e.g., a-z, 0-9)
3.  Single and no trailing hyphens.
4.  Descriptive and concise.
5.  Use branch prefixed for quick identification of purpose. (e.g., `feature/`, `bugfix/`, `docs/`)
